MBTI Carousel Scheduler ("the Tool") is a personal, non-commercial command-line utility that prepares image carousels the operator has created and sends them to the operator's own TikTok account as drafts. By using the Tool you agree to these terms.

1. What the Tool does

  • Reads image files from a folder on the operator's own computer.
  • Converts them to JPEG and publishes them to a static web host so TikTok can fetch them.
  • Calls the TikTok Content Posting API to place the images in the operator's TikTok drafts, together with a title and hashtags.

The Tool never publishes to a TikTok profile on its own. Every draft is reviewed and published manually by the account holder inside the TikTok app.
