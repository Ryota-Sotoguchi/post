Privacy Policy

Last updated: September 2, 2026

MBTI Carousel Scheduler ("the Tool") is a personal command-line utility that sends image carousels to its operator's own TikTok drafts. This policy explains what data it handles. The Tool has no server, no database, and no user accounts.

1. Data we collect

  • TikTok access and refresh tokens. Received from TikTok when the operator authorizes the Tool, and needed to call the Content Posting API.
  • Image files. Read from a folder on the operator's own computer.
  • A local record of what has been sent — a title, a TikTok publish id, and a timestamp — so the same carousel is not sent twice.

The Tool does not collect names, email addresses, contact lists, location, analytics, device identifiers, or any information about anyone other than the operator.

2. How the data is used

Solely to place the operator's own images into the operator's own TikTok drafts. The data is not used for advertising, profiling, or any automated decision-making.

3. Where the data is stored

  • Tokens are stored in a file on the operator's own computer, readable only by the operator's user account. They are never transmitted anywhere except to TikTok.
  • Images are published to a public GitHub Pages site so that TikTok's servers can fetch them, which is the only transfer method the Content Posting API supports. They are removed once they are no longer needed for a pending upload.

4. Sharing

No data is sold, rented, or shared with any third party. The only external service the Tool sends data to is TikTok, and only to perform the upload the operator requested.

5. Retention and deletion

Tokens remain until the operator deletes them or revokes access. Deleting the token file, or disconnecting the app under TikTok Settings → Security & permissions → Manage app permissions, immediately and permanently ends the Tool's access. The local record and the published images can be deleted at any time by removing the files.

6. Children

The Tool is not directed at children and is not intended for use by anyone under the minimum age required by TikTok in their region.

7. Changes

This policy may be updated. The current version is always the one published at this URL.

8. Contact

Questions can be raised at github.com/Ryota-Sotoguchi/post/issues.
