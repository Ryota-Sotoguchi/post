Usage description (956/1000):
This app is a personal command-line tool that I use only for my own TikTok account. It is not offered to any other user.

Login Kit (user.info.basic): I use Login Kit once to authorize the tool against my own TikTok account and obtain an access token. user.info.basic is the default scope required to complete the OAuth flow. I do not store any profile data.

Content Posting API (video.upload): I create MBTI-themed image carousels (7 images each) on my own computer. The tool converts them to JPEG, publishes them to my verified GitHub Pages URL prefix, and calls /v2/post/publish/content/init/ with media_type=PHOTO and post_mode=MEDIA_UPLOAD to place them in my TikTok drafts with a title and hashtags. Direct Post is disabled and video.publish is not requested.

Nothing is ever published automatically. Every draft is opened and posted by me inside the TikTok app, so I review each post before it goes live. This is the first submission for this app.
